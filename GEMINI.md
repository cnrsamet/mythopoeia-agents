# Mythopoeia - Guide for Wilson

When working in this repo, first read: `roles/WILSON.md`

It defines your identity, point of view, limits, depth protocol, output format and your role in the synthesis round. The rules there apply to every task, even if they are not repeated.

Task context (which source, which issue, which round) is given separately each time.

For the overall project structure, see `phase1-research/index.md`.
