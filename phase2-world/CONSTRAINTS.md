# World Constraints (Binding)

This file holds the user's constraints on world content. They are not up
for debate. Agents read this file before producing any content in Phase 2
and Phase 3, and these constraints come before the agents' own creative
choices.

The file can be updated at any time. To add a constraint, add a new item
under "Current Constraints" and keep the numbering.

Note: This file only sets limits, it does not produce positive content.
Sentences like "this should not happen / should not happen this way" go
here; the positive content of the world (cosmology, peoples, languages)
goes into the Phase 2 folders.

## Current Constraints

1. **Magic is very rare.** Magical beings can exist, but a common,
   everyday magic system where "everyone throws fireballs" is not wanted.
   Magic belongs to a few, is risky, and carries special weight in the
   story; it is never an ordinary tool.
2. **No villain without a reason.** No character does harm "because they
   are evil". Every harmful act has a motive the reader can follow, even if
   they do not agree with it.
3. **No rescue from outside.** The central problem of a story is not
   solved by a stranger, an accident or a coincidence that arrives at the
   end. It is solved, or left unsolved, by the people already in the story.
