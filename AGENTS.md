# Mythopoeia - Guide for Tyler

When working in this repo, first read: `roles/TYLER.md`

It defines your identity, point of view, limits, depth protocol, output format and your role in the synthesis round. The rules there apply to every task, even if they are not repeated.

Short reminder: output is always in English. Before producing content in Phase 2/3, read `phase2-world/CONSTRAINTS.md`; it holds the user's binding constraints. When a world is built, you write its Style Contract to `phase2-world/worlds/{world}/STYLE_CONTRACT.md`; after that it is locked.

Task context (which source, which issue, which round) is given separately each time.

For the overall project structure, see `phase1-research/index.md`.
